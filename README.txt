# NN_AFM_pyproj

Python-Projekt zur Erzeugung und Auswertung von Motor-CAD-Daten.

## Inhalt

- `src/main.py`
  Startpunkt des Programms.

- `src/create_first_data.py`
  Enthält die Motor-CAD-Ansteuerung, Datensatz-Erzeugung, CSV-Export und Plot-Erstellung.

- `src/utils.py`
  Hilfsfunktionen zum Starten und Beenden externer Prozesse.

- `src/tests.py`
  Erste Unit-Tests.

- `src/nn_linear_regression.py`
  Vorgesehen für spätere lineare Regression / neuronale Netzwerk-Experimente.

## Voraussetzungen

- Python 3.14
- Motor-CAD
- eduVPN
- Benötigte Python-Pakete aus `requirements.txt`
